RedGem 3D Engine for Windows (x86_64) - experimental

Run redgem.exe: the project hub opens, where you create a game or open one.
To open a demo, drag its folder (games\platformer) onto redgem.exe, or from a terminal:

  redgem.exe games\platformer

Press Play, move with WASD, jump with Space.

This build is compiled on Linux and has only been tried under Wine, not on a real Windows
machine yet: please report what breaks. It builds games for Windows; Linux and Android builds
are made from the Linux download.

Also here:

  redgem-player.exe   what a built game is a copy of
  redgem-relay.exe    the meeting point for multiplayer games over the internet

The manual: https://carlosdanielpohlod.github.io/redgem-site/manual/
